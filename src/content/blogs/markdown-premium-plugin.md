## **Tips for Pasting Text**

To paste text in plain form using keyboard shortcuts, use:

**Windows:** Ctrl+Shift+V

* **Mac:** Cmd+Shift+V

### Paste Example

Paste the following markdown into the editor using the above shortcuts:

# H1

## H2

### H3

#### H4

##### H5

###### H6
